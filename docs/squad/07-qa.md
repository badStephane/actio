## 2. Nouveaux bugs

**QA7-01 Import CSV : jour et mois inversés en silence (Majeur, Back).** Env : arbre de travail, xlsx 0.20.3, Node 24.
Étapes : CSV « ; » (Excel FR) avec `Date` = `03/04/2026`, importer. Attendu : 2026-04-03. Obtenu : 2026-03-04,
ligne valide, aucun avertissement. Toujours, pour tout jour <= 12. Cause : `XLSX.read(buffer, { type: 'array' })`
(`importRegistrations.ts:239`) laisse SheetJS convertir le texte CSV en date à l'américaine avant notre parseur
jj/mm/aaaa. Correctif proposé : `raw: true` dans les options de `XLSX.read` pour les fichiers CSV (le texte reste
du texte : dates lues par `toIsoDate`, « 5,000 » refusé explicitement). Test : `importRegistrations.test.ts`,
`it.fails('CSV : « 03/04/2026 » doit être lu 3 avril...')`.

**QA7-02 Import CSV UTF-8 sans BOM : accents abîmés (Mineur, Back).** LibreOffice / Google Sheets : `Prénoms` lu
`PrÃ©noms` (colonne non reconnue, lignes en erreur), `Médina` importé `MÃ©dina` si les en-têtes sont sans accent.
Excel (« CSV UTF-8 » avec BOM, ou CSV Windows-1252) fonctionne. Correctif : décoder en UTF-8 strict, repli
Windows-1252. Test `it.fails('CSV UTF-8 sans BOM...')`.

**QA7-03 Portée `sql` décorative (Mineur, Back).** `capabilities/default.json` limite `sql:allow-*` à
`sqlite:inscriptions.db`, mais tauri-plugin-sql 2.4.0 ne lit aucune portée (aucun `Scope` dans ses sources) :
le webview peut ouvrir une autre base SQLite du dossier de l'app. Impact faible (H2, CSP stricte). Garder la CSP
comme vraie barrière ; ne pas présenter la portée comme une protection.

**QA7-04 Runbook : copie `pre-upgrade_*` ignorée (Mineur, SRE).** `RELEASE.md` §5.11.4 cible `auto_*_vX.Y.Z.db`
(tournante, perdue après 10 lancements) alors que `pre-upgrade_v<ancienne>_to_v<nouvelle>_*.db` est la copie
pré-migration hors rotation. Le smoke §3 ne vérifie pas sa présence.

**QA7-05 Emplacement des sauvegardes introuvable (Mineur, Front + Back).** `BACKUP_DIR_LABEL` = « dossier de
l'application / backups » ; le dialogue de restauration ne s'ouvre pas dans ce dossier. Un opérateur ne retrouve
pas `%APPDATA%\com.badstephane.gestion-inscription\backups` sans aide. Afficher le chemin réel (commande Rust).

**QA7-06 Montants texte ou négatifs ramenés à 0 sans entrer au contrôle des imports (Mineur, Back).** Migration 11 :
la valeur d'origine n'est conservée que dans `audit_events` (test « montant texte -> 0 »), que l'opérateur peut
effacer (`clearAuditLog`), et pas dans `amount_review`.
